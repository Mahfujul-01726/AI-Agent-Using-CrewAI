# AI Agent Using CrewAI

This project demonstrates the use of CrewAI to create AI agents that can perform research and write content. It includes two main scripts:
- `main.py`: Automated AI healthcare research with researcher and writer agents
- `research_agents.py`: Interactive research agent that lets you specify topics

## Prerequisites

- Python 3.11 or higher
- OpenAI API Key ([Get it here](https://platform.openai.com/api-keys))
- Serper API Key ([Get it here](https://serper.dev/api-key))

## Quick Start

### 1. Clone the Repository

```bash
git clone <repository-url>
cd AI-Agent-Using-CrewAI
```

### 2. Run Setup Script

The easiest way to set up the project is to use the automated setup script:

```bash
./setup.sh
```

This script will:
- Check for Python installation
- Create a virtual environment
- Install all dependencies
- Create a .env file from .env.example

### 3. Configure API Keys

Edit the `.env` file and add your API keys:

```bash
nano .env  # or use your preferred editor
```

Add your keys:
```
OPENAI_API_KEY=your_actual_openai_api_key
SERPER_API_KEY=your_actual_serper_api_key
```

### 4. Run the Project

Use the run script for an interactive menu:

```bash
./run.sh
```

Or run the scripts directly:

```bash
# Activate virtual environment first
source venv/bin/activate

# Option 1: Run automated AI healthcare research
python main.py

# Option 2: Run interactive research agent
python research_agents.py
```

## Manual Setup (Alternative)

If you prefer manual setup or if you're using Conda:

### Using Conda

```bash
# Create conda environment
conda create -n llmapp python=3.11 -y

# Activate environment
conda activate llmapp

# Install dependencies
pip install -r requirements.txt

# Create .env file and add your API keys
cp .env.example .env
# Edit .env with your API keys
```

### Using venv

```bash
# Create virtual environment
python3 -m venv venv

# Activate virtual environment
# On Linux/Mac:
source venv/bin/activate
# On Windows:
# venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create .env file and add your API keys
cp .env.example .env
# Edit .env with your API keys
```

## Features

### main.py
- Creates a Senior Researcher agent and a Writer agent
- Researches AI trends in healthcare
- Generates a comprehensive blog post in markdown format
- Saves output to `new-blog-post.md`

### research_agents.py
- Interactive research agent
- Allows you to specify custom research topics
- Uses GPT-3.5-turbo for research and synthesis
- Displays results in the console

## Troubleshooting

### Missing API Keys
If you see errors about missing API keys:
1. Make sure you created the `.env` file
2. Verify your API keys are correct
3. Check that there are no extra spaces or quotes around the keys

### Installation Issues
If you encounter installation issues:
```bash
# Update pip
pip install --upgrade pip

# Try installing dependencies one by one
pip install crewai==0.22.5
pip install 'crewai[tools]'
pip install langchain_openai langchain_community python-dotenv
```

### Virtual Environment Issues
If virtual environment is not working:
```bash
# Remove existing venv
rm -rf venv

# Recreate it
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
